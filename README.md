# The World Today — 24 November 2026

This repository is an entry for the make.fun bounty **Sum up 24 November's world news in one image** (`news-image-20261124`). It renders Tuesday 24 November 2026's world headlines in a single 1024×1024 newspaper front page (`entry.png`), composed deterministically with Pillow by `compose.py` from custom editorial artwork and validated typography. Running `main.py` (Python 3.13, standard library only) copies `entry.png` into `$MAKEFUN_OUTPUT_DIR/entry.png` (defaulting to `/output/entry.png`), ensuring byte-identical output across repeated runs.
